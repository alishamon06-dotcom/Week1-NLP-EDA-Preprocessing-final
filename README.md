# Week 1 NLP Project: Exploratory Data Analysis and Preprocessing

## Project overview
This project explores the UCI SMS Spam Collection dataset. The aim is to understand the data, check its quality, study message lengths and common terms, and prepare the text for later NLP work.

## Dataset
- Source: UCI Machine Learning Repository — SMS Spam Collection
- Dataset page: https://archive.ics.uci.edu/dataset/228/sms+spam+collection
- DOI: https://doi.org/10.24432/C5CC84
- Original size: 5,574 English SMS messages
- Labels: `ham` (ordinary message) and `spam` (unwanted message)

The script downloads the dataset the first time it is run. The raw dataset is not included in this repository.

## Run the project
Open a terminal in this project folder and run:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python src_eda.py
```

The script creates an `outputs/` folder containing the cleaned data, summary statistics, frequency tables and charts. Internet access is needed on the first run if the dataset is not already present locally.

## What the project covers
- Dataset size, labels, missing values and duplicate records
- Character and word counts
- Frequent unigrams and bigrams
- Lowercasing, URL and number placeholders, tokenization and stop-word filtering
- Optional VADER sentiment analysis for a separate descriptive view

## Important note
The dataset's actual labels are `ham` and `spam`. VADER sentiment is only an additional estimate of positive, neutral or negative wording. It is not a spam classifier and is not used as a model evaluation score.

## Reproducibility
The numerical results and charts in `outputs/` are generated by `src_eda.py`. Run the script again to recreate them from the downloaded UCI dataset.
